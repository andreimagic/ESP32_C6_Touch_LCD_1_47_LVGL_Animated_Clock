User Manual

📱 The Home Screen

The clock uses a minimalist, gesture-based interface. There are no visible buttons on the main face; instead, the screen is divided into four invisible touch zones.

1. Emotion Mode (Upper-Left)

Tapping the upper-left area opens a full-screen GIF animation (usually a smile). While this screen is open, Emotion Tilt is active. You can change the emotion by tilting the device:

  • Upright: Smile GIF
  • Tilt Backwards: Sleep GIF
  • Tilt Forwards: Sad GIF
  • Tilt Left/Right: Joy GIF

Note: Long-pressing the Smile GIF is the secret entrance to the Apps Menu.

2. Analog Clock (Upper-Right)

Tapping the upper-right area opens a live analog clock. It features a dynamic "pie-sector" sweep that fills as the hour progresses, providing a visual representation of the time elapsed in the current hour.

3. Status Screen (Lower-Left)

Displays the current date, WiFi connection status (SSID), and NTP sync state. While this screen is open, you can tilt the device left or right to adjust the screen brightness in 10% increments. Long-pressing on this screen opens a popup showing the Web Configuration PIN and access address.

4. Battery Screen (Lower-Right)

Shows real-time battery percentage, voltage, and raw ADC values. To power off the device, long-press on this screen to trigger a 5-second shutdown countdown.

⚙️ System Settings (The Carousel)

To enter the system settings, long-press anywhere on the home screen. This opens the Carousel menu.

Use the ◀ and ▶ arrows on the edges of the screen to swipe through the settings. Tap the center to enter a specific editor, or long-press to exit back to the clock.

SettingFunctionHow to use
ClockDate & TimeAdjust HH:MM and DD/MM/YYYY using ▲/▼. Long-press to save.
TimerCountdownSet duration. Toggle to "Ready!" and long-press to start.
AlarmWake-up CallSet time and toggle ON/OFF. Long-press to save.
WiFiConnectivityTap to toggle WiFi on/off. Access the AP PIN and IP via the detail popup.

🎮 Apps Menu & Games

The Apps Menu is hidden behind a "Math Gate" to keep kids entertained and challenged.

How to Enter:

  1. Tap Upper-Left (Emotion Mode).
  2. Long-press the GIF.
  3. Solve the random arithmetic problem by tapping the correct answer.

Available Apps:

  • Rock Paper Scissors: An interactive game against the CPU. Shake or hard-tilt the device to play again instantly.
  • Rolling Dice: An animated dice roller. Shake the device to re-roll.
  • Flip a Coin: A quick ASCII coin toss. Tap to flip.
  • Metronome: A professional-grade tool. Use the slider for BPM (60-240), select time signatures (2/4, 3/4, 4/4), and follow the 🔴/🟢 beat dots.
  • Tennis Letters: A Breakout-style game. Tilt the device to move the paddle and catch cycling letters from a to z.
  • Letters Rain: A challenging game where letters fall in waves. Catch the target letter while dodging decoys and using modifiers (+ / - / *) to resize your paddle.
  • Snake Letters: A classic snake game. Use tilt to eat letters in alphabetical order (a-z). Be careful: after reaching a certain score, "distraction" letters appear—touching them ends the game! Look out for modifiers: - shrinks your snake, and / halves its length. Tap the screen to pause, and long-press the pause menu to exit.
  • Bingo!: An on-device 1–90 number caller. Tap anywhere, or tilt the device left/right, to draw the next ball — a large circle plays a cycle-and-reveal animation with a buzzer pattern before showing the number. Long-press inside the circle to see the full call history; long-press anywhere else to exit. Numbers never repeat within a game. Pair it with a printed ticket from the Web Configuration page.

🌙 Automation & Power

Daily Brightness & Animation Schedule

The clock automatically adjusts its behavior based on the time of day:

TimeAction
06:00 — 07:00Brightness gradually increases from 10% to 50%.
07:00 — 19:59Scheduled animations use the Smile GIF.
19:00 — 20:00Brightness gradually decreases from 25% to 1%.
20:00 — 06:59Scheduled animations use the Sleep GIF.

Deep Sleep & Waking

When the device is powered off via the Battery screen, it enters a low-power deep sleep. To wake the device, press the physical RESET button on the board.

Alarm Auto-Wake: If an alarm is set, the device will automatically wake up 5 minutes early to sync time via NTP, ensuring your alarm fires at the exact second.

🌐 Web Configuration

You can manage your clock from any web browser without needing a cable.

Connecting:

  • Home Network (STA): Go to http://esp32clock.local.
  • Direct Connection (AP): Connect to the WiFi hotspot ESP32-Clock. The password is the 6-digit PIN shown on the device screen (Carousel → WiFi). Then go to http://192.168.4.1.

The Web Interface:

Once connected, enter the 6-digit PIN to unlock the following features:

  • Config Editor: Edit config.ini directly (WiFi, Timezone, Alarm settings).
  • Quick Time Set: Use the date/time picker to set the clock instantly.
  • Remote Reboot: Restart the device from your browser.

No PIN needed: the 🎫 Bingo Cards button opens /bingo in a new tab — a printable sheet of UK/housie-style tickets (3×9, 1–90) generated fresh in your browser to pair with the on-device Bingo! caller. Choose 4, 6, or 8 tickets per page, then print.
